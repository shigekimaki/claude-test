# claude-test

Claude Code (claude.ai/code) を試すための個人用サンドボックスリポジトリ。

## 用途

このリポジトリは特定のプロダクトではなく、以下を気軽に試すための場所:

- プロンプトやスラッシュコマンドの挙動確認
- ツール (Read/Edit/Bash/Agent など) の動作検証
- `settings.json`・hooks・MCP の設定実験
- 軽い書き捨てスクリプトのスケッチ

## 使い方

このディレクトリで Claude Code を起動するだけ:

    cd claude-test
    claude

中のコードやファイルは実験用であり、いつでも書き換え・削除される前提です。

## メモ

- 安定動作や後方互換は保証しない
- 機密情報・認証情報はコミットしないこと
